# Wiki Configuration

## Scope

This wiki documents the components that make up the Stratio product — their architecture,
configuration, operation, and how they fit together. It is shared with the team as the
`stratio-wiki` GitHub repository.

## Conventions

- This is a **local wiki** rooted at the repository root (not nested under `.wiki/`), so
  content is fully visible when browsing the repo on GitHub. A `.wiki -> .` symlink is kept
  at the root purely so `/wiki:*` commands auto-resolve here without needing `--local`.
- Nothing in this wiki is gitignored — all of `inbox/`, `raw/`, `wiki/`, and `output/` are
  meant to be committed and shared.
